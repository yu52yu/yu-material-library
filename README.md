# 瑜の素材库 · Yu Material Library

Windows 本地设计素材管理工具。素材保存在你自己选择的文件夹中；本仓库只保存程序源码和界面资源，不同步本地素材图片。

**v0.12.0 已发布，并已在本机完成更新。** 本版新增项目关联、四种依据的升降序排列、窗口状态记忆及紧凑“添加”入口，详情见 [开发日志](开发日志.md)。

用户已回复“就这样”，批准恢复改版前的界面：以 `7e3bc15` / v0.11.6 为基线，仅保留紧凑无闪白的“添加”按钮及删除介绍小字，项目关联、排列和窗口记忆保留。目标版本 **v0.12.1** 正在准备正式发布与本机更新，尚未部署；当前正式下载仍为 v0.12.0。

## 在另一台电脑使用

- 直接安装：登录有仓库访问权限的 GitHub 账号，在 [v0.12.0 下载页](https://github.com/yu52yu/yu-material-library/releases/tag/v0.12.0) 下载 `YuMaterialLibrary-0.12.0-Setup.exe`。安装包自带运行环境，无需另装 Node.js 或 pnpm。
- 版本说明：截至 2026-10-15，主分支源码与最新正式安装包均为 **v0.12.0**。源码更新仍需单独构建并发布安装包。
- 查看或修改源码：克隆仓库，安装 Node.js 和 pnpm，运行 `pnpm install`。使用 `pnpm run desktop` 启动桌面版，或运行 `pnpm run build:desktop` 生成 Windows 安装包。
- 首次打开后，通过“添加 → 打开素材库…”选择那台电脑自己的素材文件夹，或使用“添加 → 创建素材库…”建立基础目录。每台电脑独立设置项目名、分类名和本机收藏备注，安装包不带入这台电脑的文件夹命名、路径、设置或素材。
