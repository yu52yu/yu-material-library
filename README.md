# 瑜の素材库 · Yu Material Library

Windows 本地设计素材管理工具。素材保存在你自己选择的文件夹中；本仓库只保存程序源码和界面资源，不同步本地素材图片。

**v0.12.1 已发布，并已在本机完成更新。** 界面恢复为改版前 `7e3bc15` / v0.11.6 的配色、字号、间距、控件和文案，仅保留紧凑无闪白的“添加”按钮及删除介绍小字；项目关联、排列和窗口记忆保留。详情见 [开发日志](开发日志.md)。

## 主要功能

- 连接本地素材目录或外部项目文件夹，支持预览、搜索、分类、收藏与备注。
- 支持项目素材关联、文件排序、批量整理及拖拽原文件到设计工具。
- 通过原生文件变化通知增量更新；缩略图缓存与个人设置保存在本机。
- 删除前确认原文件，并通过 Windows 回收站处理；批量失败项可重试。

## 在另一台电脑使用

- 直接安装：在 [v0.12.1 下载页](https://github.com/yu52yu/yu-material-library/releases/tag/v0.12.1) 下载 `YuMaterialLibrary-0.12.1-Setup.exe`。安装包自带运行环境，无需另装 Node.js 或 pnpm。
- 版本说明：截至 2026-10-15，主分支源码与最新正式安装包均为 **v0.12.1**。源码更新仍需单独构建并发布安装包。
- 查看或修改源码：克隆仓库，安装 Node.js 和 pnpm，运行 `pnpm install`。使用 `pnpm run desktop` 启动桌面版，或运行 `pnpm run build:desktop` 生成 Windows 安装包。
- 首次打开后，通过“添加 → 读取素材库文件夹”选择那台电脑自己的素材文件夹，或使用“添加 → 创建基础目录结构”建立基础目录。每台电脑独立设置项目名、分类名和本机收藏备注，安装包不带入这台电脑的文件夹命名、路径、设置或素材。
