# 瑜の素材库 · Yu Material Library

Windows 本地设计素材管理工具。原文件保存在你自己选择的本地文件夹中，分类、标签和备注另存为本机整理资料库；本仓库只保存程序源码和界面资源，不同步本地素材或设置。

**当前源码版本：v1.1.0。** 新增自定义顶层素材区，方便单独管理与项目无关的个人作品，保留独立资料库功能、紧凑标题布局及侧栏抖动修复。[Windows x64 安装包](https://github.com/yu52yu/yu-material-library/releases/download/v1.1.0/YuMaterialLibrary-1.1.0-Setup.exe) · [v1.1.0 发布页](https://github.com/yu52yu/yu-material-library/releases/tag/v1.1.0)。详情见 [安装说明](安装说明.md)。

## v1.1.0 功能

- “原位连接文件 / 原位连接素材文件夹”只记录原文件地址，原图、视频和源文件不复制。拖出使用原始文件，不重新编码或压缩。
- 点击左侧“素材”旁的“＋”（新增素材区），填写“素材区名称”并点击“创建”，即可建立自己的顶层素材区；原有下载素材、AI制作素材及项目保留。创建只保存整理记录，实际添加或移动文件时才按所选操作创建存放目录。
- 下载素材、AI制作素材及自定义素材区支持各自的多级虚拟分类，例如“动物 → 鱼 → 海水鱼”；同一文件可属于多个分类，分类操作不新建对应磁盘文件夹。图片、视频共用主题分类，媒体类型独立筛选。
- 独立编辑库内显示名称、标签和备注；全库搜索覆盖文件名、路径、显示名称、备注、标签及分类，支持收藏入口、媒体类型及标签组合筛选。
- 搜索范围、类型、只看收藏和标签筛选并入上方标题区，收紧间距；素材数仅显示“N 个素材”，去掉后面的素材库目录名。
- SQLite 整理资料库保存固定素材身份和整理记录。原文件暂时离线时保留记录，可重新定位；旧版收藏、备注、项目关联等进行一次迁移，保留迁移原始快照及旧本地设置键。
- 可选择资料库与缓存保存位置，查看空间占用，备份或恢复整理信息。预览缓存默认上限 512 MB，可设为 128–4096 MB，也可单独清理；整理备份不包含原始素材。
- 既有项目物理目录和项目关联保留。“复制文件到…”明确复制；外部新文件拖入仍移动，在通用素材区进入稳定的物理“未分类”目录，再记录虚拟分类归属。
- 侧栏悬停时不再横向位移，滚动条预留宽度固定；长项目名省略显示，分类操作在窄侧栏中换行。

本版不附带演示素材。v1.1.0 已通过生产构建、161 项桌面测试、4 项静态服务检查和 6 项隔离 Electron 流程验证，覆盖素材区创建、文件接入、分类、重开及备份恢复；125% 缩放下的窄窗口和不同侧栏宽度均无悬停抖动或横向溢出。实际安装版仍读取 236 个素材、4 个分类、1 个收藏和 5 个项目连接，7 项整理设置与 9 个本地设置键均保留；安装前备份的 365 个用户数据文件在首次启动前校验全部一致。

历史验证：v1.0.0 交付时通过 144 项桌面回归及 4 项静态服务检查，前端构建与最后评审版逐字节一致，305 个用户数据文件在首次启动前校验一致。v1.0.1 只改两个 CSS 文件，通过 125% 缩放、180/208.8/360 像素侧栏专项检查，313 个备份文件在首次启动前校验一致，未重跑业务回归。2026-10-16 的 v0.13.0 评审另通过 8 项隔离 Electron 流程检查及原文件拖出路径、内容校验；Photoshop 等目标应用的实际接收行为未在本次重新验证。

## 主要功能

- 连接本地素材目录或外部项目文件夹，支持预览、搜索、分类、收藏与备注。
- 支持项目素材关联、文件排序、批量整理及拖拽原文件到设计工具。
- 通过原生文件变化通知增量更新；缩略图缓存与个人设置保存在本机。
- 删除前确认原文件，并通过 Windows 回收站处理；批量失败项可重试。

## 在另一台电脑使用

- 直接安装：从 [v1.1.0 发布页](https://github.com/yu52yu/yu-material-library/releases/tag/v1.1.0) 下载 `YuMaterialLibrary-1.1.0-Setup.exe`，在 Windows x64 电脑上双击安装。安装包自带运行环境，无需另装 Node.js 或 pnpm。
- 查看或修改源码：克隆仓库，安装 Node.js 和 pnpm，运行 `pnpm install --frozen-lockfile`。使用 `pnpm run desktop` 启动桌面版，或运行 `pnpm run build:desktop` 生成 Windows 安装包。要取得与安装包对应的精确源码，检出 `v1.1.0` 标签。
- 首次打开后，通过“添加 → 读取素材库文件夹”选择那台电脑自己的素材文件夹，或使用“添加 → 创建基础目录结构”建立基础目录；也可使用“原位连接文件 / 原位连接素材文件夹”。每台电脑独立设置项目名、分类名和本机收藏备注，安装包不带入这台电脑的文件夹命名、路径、设置或素材。
